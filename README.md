## 설치 방법 (컴퓨터 · 공유 폴더마다 처음 한 번)

1. 위 **본관 설치 받기**를 눌러 zip 을 받고 압축을 풀어요.
2. `황소onY_본관` 폴더를 통째로 공유 폴더 등 프로그램을 둘 곳에 복사해요.
3. `토큰.txt` 를 메모장으로 열어, 영은님께 **따로** 받은 열쇠(`github_pat_...`) 한 줄을 붙여넣고 저장해요.
4. `run.bat` 더블클릭 → 처음 켤 때 프로그램을 받아서 실행해요 (인터넷 필요).
   - 파이썬이 없으면 자동으로 설치해요 (처음 한 번 · 몇 분). 안 되면 [python.org](https://www.python.org/downloads/) 에서 직접 설치, 첫 화면에서 **Add python.exe to PATH** 체크
   - 필요한 부품은 자동으로 설치돼요.
   - 처음 켜면 **처음 설정**: 담당자 → 공유 폴더 → 시간표 → 보충 → 진도계획표 → 벌점 → 선생님·밴드 → 정원 → 승강급 파일
5. 그다음부터는 `run.bat` 만 누르면 켤 때마다 최신 버전으로 바뀌어요.

## 알아 두기

- 이 저장소에는 설치 파일만 있어요. 프로그램 · 학생 정보 · 열쇠는 없어요.
- `토큰.txt` 의 열쇠는 단톡방 등 다른 곳에 올리지 마세요.
- `관.txt` 는 바꾸지 마세요 (`본관`).
- 문제가 생기면 프로그램 폴더의 `bogang_bon.py.이전` 이 바로 전 버전이에요.
